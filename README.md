# NoteNest

NoteNest is a simple note-taking application created as a practice project while learning full-stack software engineering, Git, and GitHub.

## About

This project is being used to learn and practice Git and GitHub concepts such as repositories, commits, branches, remotes, and pushing changes to GitHub.

## Current Features

- Basic NoteNest homepage
- HTML structure
- Git version control
- GitHub repository
